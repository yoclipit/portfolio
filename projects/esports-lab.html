E-sports lab network and server plan

Planning a reliable, secure gaming café environment for a target of 50 concurrent users.

The assignment

Our five-person project team planned a campus gaming café and e-sports lab. The proposed environment needed low-latency wired and wireless connectivity, gaming endpoints, security, support processes, and a path from procurement through handover.

My contribution

I was assigned the network/server area. I produced a work breakdown structure that turned broad goals into concrete planning tasks:

  • Gather user, device, bandwidth, availability, and security requirements.
  • Plan logical and physical network diagrams, IP addressing, VLAN segmentation, and wireless coverage.
  • Evaluate routers, switches, firewalls, cabling, servers, warranties, and support.
  • Define server roles such as file, database, and directory services; plan permissions, backup, VPN, and protection controls.
  • Specify connectivity, access, and performance checks, then document the environment for handover.

What the evidence shows

The individual network/server WBS and the team project portfolio document a proposed design and project process. They show requirements and implementation planning, not proof that hardware was installed or a production network was operated. The 50-user figure is a design target.

Project scope: Academic planning case study. Any future implementation would need actual topology and configuration diagrams, measured performance, security test results, and stakeholder sign-off.
