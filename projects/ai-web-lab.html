AI-integrated web lab

A web interface combining image classification, model comparison, and PDF résumé analysis.

What I built

The browser loads MobileNet through TensorFlow.js to classify a selected or uploaded image. A separate Node.js server exposes an image-description endpoint that requests responses from four models, and a résumé endpoint that extracts text from an uploaded PDF and sends it for an AI review.

Why the split matters

Image classification runs in the browser. Requests that need provider credentials run through the local server, where the API key is read from an environment variable. The interface displays model responses and handles failed requests.

Current state

This is a local coursework prototype. The AI endpoints require a running server and provider credentials, so this static portfolio does not present them as a live public demo. A next step would be to harden upload limits, output encoding, access control, and error handling before any public deployment.

The school folder contains a local .env file. It is intentionally excluded from this portfolio and must never be uploaded with source code.
