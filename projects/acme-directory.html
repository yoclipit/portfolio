ACME directory and licensing design

Structuring a fictional organization's directory and evaluating software licensing options.

Directory model

I mapped a fictional ACME organization to an acme.local domain, an executive parent, and Marketing, Research, Sales, and HR organizational units. The exercise placed users, workstations, servers, NAS resources, and printers under departments, with an additional database server for HR.

License comparison

The assignment also asked for a cost recommendation for 1,000 users with 60% simultaneous use:

OptionCalculationCost
Named workstation1,000 × $229$229,000
Interactive user600 × $299$179,400
Company-wideFixed price$200,000

At this usage level, the interactive license has the lowest calculated cost. The company-wide option becomes cheaper than interactive licensing at 669 simultaneous users.

This is a design and cost-analysis exercise. It does not show a deployed Active Directory environment or real purchasing decision.
