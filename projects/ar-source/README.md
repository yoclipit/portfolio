# AR retail app code samples

These five C# files are selected from Julian Medina's Unity coursework project. They rely on Unity, AR Foundation, scene objects, and prefabs that are not included here.

`CanvasSwitcher.cs` was copied from the original `SceneLoader.cs`. The filename was normalized to match the `CanvasSwitcher` MonoBehaviour class; the source code itself was not edited.

For project context, see [the case study](../ar-retail.html).
